# Protocol Security Lab

Simulation-first smart-contract research kept for learning and repeatable testing.

## Challenge Simulations

[`challenge-simulations/`](challenge-simulations/) contains:

- Tenderly and local-fork simulation helpers
- Public contract source snapshots
- Contract-state and function-review scripts
- Historical Alpha Challenge research notes

Start with the [simulation guide](challenge-simulations/README.md).

These tools are for local forks, virtual networks, and historical analysis. Keep API keys, RPC credentials, wallet keys, and generated results outside git.
